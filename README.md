---## 🎯 项目简介

竞技排行榜是一款专为团队竞技比赛设计的**实时排名与淘汰赛预测系统**，适用于电竞、体育等各类团队对抗赛事。

系统支持：
- 从数据源自动读取比赛结果，实时计算排名
- 将战队参赛数据按多维度进行智能排序
- 基于当前排名自动生成淘汰赛对阵并预测晋级者

### 核心优势

- 📊 **智能排序** - 基于胜负分、净胜分、胜场数的多维度综合排名
- ⚡ **极速加载** - 一键从剪贴板读取数据，秒级更新
- 🔄 **自动刷新** - 定时自动检测更新（10秒-5分钟可选）
- 🏆 **淘汰赛预测** - 自动生成完整多轮分支图，基于EPA预测每轮获胜者
- ⭐ **重点关注** - 支持将特定战队置顶显示详细数据
- 🎨 **精美界面** - 渐变配色、响应式设计、动画效果
- 📱 **全平台** - 支持PC、平板、手机，无需安装---## ✨ 功能特点

---## 📖 使用说明

### 📊 排行榜模块

#### 方法1: 快速读取（⭐ 推荐）

1. 打开数据表格（如金山文档、Excel等）
2. 选中**整个表格**（包括标题行）
3. 复制数据 (Ctrl+C / Cmd+C)
4. 点击 "⚡ 快速读取剪贴板" 按钮
5. 立即查看排名结果

#### 方法2: 自动刷新（⚡ 最方便）

1. 首次使用方法1加载数据
2. 勾选 "自动刷新" 复选框
3. 选择刷新间隔（建议30秒）
4. 当数据更新时，复制新表格
5. 系统自动检测并更新排名

#### 方法3: CSV文件上传

1. 从数据源导出CSV文件
2. 点击 "从金山文档加载" 选择数据源
3. 上传CSV文件
4. 查看解析结果

#### 方法4: 手动输入

1. 选择 "手动输入" 数据源
2. 按CSV格式输入数据
3. 点击 "解析数据" 按钮

#### 功能使用

- **🔍 搜索战队** - 在搜索框输入战队名称快速筛选
- **⭐ 添加关注** - 点击战队行或使用"管理关注"按钮添加特定战队
- **📈 排序** - 点击表头列名可按该列排序（升序/降序）

### 🏆 淘汰赛预测模块

#### 使用步骤

1. 切换到 "🏆 淘汰赛预测" 标签页
2. 粘贴**联盟选择表格**数据（包含队伍编号、名称、配置）
3. 点击 "🛠️ 生成淘汰赛赛程" 按钮
4. 查看完整的多轮分支图和预测结果

#### 表格格式

联盟数据应包含以下信息：
- 联盟编号
- 联盟名称
- 配置1的战队信息（编号、名称）
- 配置2的战队信息（编号、名称）

**示例：**

```
联盟编号  联盟名称  排名  战队编号  战队名称  排名  战队编号  战队名称
1        联盟1    1    X228841   白狼      24   X228709   渊图
2        联盟2    2    X235583   duck不必  33   X235487   baby无耻
```

#### 预测原理

- 🎯 **首尾对战** - 排名第1队 vs 排名最后队，第2队 vs 倒数第2队，依次类推
- 📊 **EPA计算** - 每个联盟的总EPA = 配置1队伍EPA + 配置2队伍EPA
- ⚔️ **晋级预测** - 基于总EPA值，EPA高的预测晋级下一轮
- 🏆 **冠军诞生** - 最后一轮获胜者成为冠军---## 📊 表格格式

系统支持以下格式的比赛数据表格（红蓝双方分别对应两列战队数据）：

| 列号 | 字段名称 | 说明 |
|------|---------|------|
| 0 | 场地 | 比赛场地编号 |
| 1 | 场次 | 比赛场次编号 |
| 3 | 红方战队1名称 | 红方第一支队伍名称 |
| 5 | 红方战队2名称 | 红方第二支队伍名称 |
| 7 | 蓝方战队1名称 | 蓝方第一支队伍名称 |
| 9 | 蓝方战队2名称 | 蓝方第二支队伍名称 |
| 10 | 红方胜负分 | 红方获得的胜负积分 |
| 11 | 红方总分 | 红方总得分 |
| 12 | 红方净胜分 | 红方净胜分（可为负） |
| 13 | 蓝方胜负分 | 蓝方获得的胜负积分 |
| 14 | 蓝方总分 | 蓝方总得分 |
| 15 | 蓝方净胜分 | 蓝方净胜分（可为负） |

**示例表格：**

```
场地  场次  红方战队1  红方战队1名称  ...  红方胜负分  红方总分  红方净胜分  蓝方胜负分  蓝方总分  蓝方净胜分
E1    1    X234657    玉泉承德      ...  0           600       -160        3           760       160
```

### EPA（场均得分）计算公式

```
EPA = 总分 / 比赛场次 / 2
```

系统会自动计算每支队伍的EPA值，用于排序和淘汰赛预测。---## 🎯 排名规则

排名按以下优先级进行多维度排序：

1. **胜负分总和** ⬆️ （最高优先级）
   - 所有比赛的胜负积分累计

2. **净胜分总和** ⬆️ （第二优先级）
   - 胜负分相同时，比较净胜分
   - 正值越大排名越前

3. **胜场数** ⬆️ （第三优先级）
   - 净胜分相同时，比较胜场数

4. **总分** ⬆️ （最终参考）
   - 以上都相同时，比较总得分

### 排名特色

- 🥇 第一名：金色高亮 + 金牌图标
- 🥈 第二名：银色高亮 + 银牌图标
- 🥉 第三名：铜色高亮 + 铜牌图标
- ⭐ 重点战队：单独置顶展示

## 🏆 淘汰赛预测

### 预测规则

**首尾对战原则：**
- 排名第1队 vs 排名最后队
- 排名第2队 vs 排名倒数第2队
- 以此类推...

**晋级预测方式：**
- 基于联盟**总EPA值**进行预测
- EPA = 配置1队伍EPA + 配置2队伍EPA
- EPA高的联盟预测晋级下一轮
- 如果EPA相等，标注"势均力敌"

### 支持的场景

- ✅ 2队、4队、8队、16队、32队、64队等 2^n 支队伍
- ✅ 3队、5队、6队等奇数队伍（自动轮空处理）
- ✅ 任意数量队伍（自动向上补齐2^n）

### 预测效果

- 📊 **多轮展示** - 从初轮到冠军的完整分支图
- 🎯 **晋级路径** - 清晰展示每支队伍的晋级过程
- 🏆 **冠军突出** - 最后的获胜者以特殊卡片展示
- 📈 **可视化分析** - 易于理解复杂的对阵关系
